E-Commerce Website
This project is a simple e-commerce website built with HTML, CSS, and JavaScript. It features a responsive design, a navigation bar, a hero section, product listings, banners, a newsletter signup form, and a footer with contact information and social media links.

Project Structure
The project consists of the following files:

index.html.html: The main HTML file that contains the structure of the website.
style.css: The CSS file that contains the styles for the website.
script.js: The JavaScript file that contains the functionality for the navigation bar.
Features
Header
The header section contains the logo and the navigation bar. The navigation bar includes links to different pages of the website such as Home, Shop, Blog, About, Contact, and Cart.

Hero Section
The hero section features a background image, a heading, a subheading, and a call-to-action button.

Features Section
The features section highlights the key features of the website, such as free shipping, online order, saving money, promotions, happy sell, and 24/7 support.

Products Section
The products section displays a list of featured products with images, descriptions, ratings, and prices. Each product has an "Add to Cart" button.

Banners
The website includes multiple banner sections that promote special deals and new arrivals.

Newsletter Signup
The newsletter signup section allows users to enter their email address to receive updates about the latest shop and special offers.

Footer
The footer contains contact information, social media links, and additional links such as About Us, Delivery Information, Privacy Policy, Terms & Conditions, and more.

Responsive Design
The website is designed to be responsive and adapts to different screen sizes. The navigation bar becomes a fixed sidebar on smaller screens, and the layout of the sections adjusts accordingly.

JavaScript Functionality
The JavaScript file (script.js) contains the functionality for the navigation bar. It includes event listeners for the hamburger menu and the close button to toggle the visibility of the navigation bar on smaller screens.
